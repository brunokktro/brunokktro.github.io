    Code blocks

    The :code directive displays copyable, syntax-highlighted code snippets and terminal output. It supports text, leaf and container declarations.

    Properties

    NameTypeDescriptionDefault
    languagestringLanguage for syntax highlighting (leaf/container only). Full list below.-
    showLineNumbersbooleanDisplays line numbers (leaf/container only).true if language is set
    showCopyActionbooleanDisplays the copy button.true if showLineNumbers is true
    highlightLinesstringComma-separated line numbers and ranges to highlight.-
    highlightLinesStartnumberStarting index used to track highlighted lines.-
    lineNumberStartnumberFirst line number to display (>= 1).1
    copyAutoReturnbooleanAppends a newline to the copied text (auto-executes in a terminal).-

    Inline code variant (text)

    Rendered:

    Your current region is us-west-2.

    1

    Auto-return on copy

    copyAutoReturn=true appends a newline to the copied text so a command runs as soon as it is pasted into a terminal. It does not add a visible line to the display.

    Rendered:

    npm start

    Source:

    1
::code[npm start]{showCopyAction=true copyAutoReturn=true}
